# Merry Christmas · 圣诞相册

用照片装饰一棵互动 3D 圣诞树。支持切换树形、散开和照片聚焦，也可以用鼠标或触屏转动散开的场景。

## 本地预览

在项目目录执行 `node server.js`，打开 <http://127.0.0.1:8080/>。无需安装 npm 依赖或运行构建。3D 场景通过 CDN 加载 Three.js，启用手势之后才加载 MediaPipe 和手部识别模型。

## 玩法

- 通过「添加照片」或「选择文件夹」导入，最多显示 60 张照片，含 3 张示例图。导入的照片经过缩放后保存在当前浏览器的 IndexedDB 中，刷新或重开同一个网址时会自动恢复。清除网站数据会移除这些照片，换浏览器或设备时需要重新导入。使用「清空导入」可以删除已保存的导入照片。
- 点击缩略图聚焦相应照片，再次使用「聚焦」可切换下一张。按 `H` 可切换演示模式。
- 点击「启用手势」并允许使用摄像头。握拳恢复树形，张开手掌散开，捏合拇指与食指聚焦。摄像头需要 HTTPS 或本机地址。

## 静态托管

将仓库根目录作为 GitHub Pages 发布源即可。入口是小写的 `index.html`，静态资源使用相对路径，适用于项目子路径。
